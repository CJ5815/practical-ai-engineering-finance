# Week 19: Reading — Loops, Expertise, and Self-Evolving Skills

> **Full lesson content:** This page is the day-by-day schedule and checklist. For the complete lesson — paper summaries, guided discussion, and connections to `sec_thesis` and the Week 17 investment-philosopher skill — see [week-19_Practical_AI_Engineering_for_Finance.md](week-19_Practical_AI_Engineering_for_Finance.md).

## Objective

Read and discuss three recent papers on agentic AI engineering, and connect
each one to a specific part of this course's own architecture: the
`sec_thesis` CLI (Week 18) and the `investment-philosopher` skill (Week 17).

The three papers (included in full under `docs/resources/papers/`):

1. *Loop Engineering: The Anthropic Playbook for Designing Systems That Prompt Your Agents*
2. *Agentic Coding and Persistent Returns to Expertise* (Anthropic)
3. *SkillOpt: Executive Strategy for Self-Evolving Agent Skills* (Microsoft et al.)

## Required Output

A short written reflection (`week19_reflection.md`) mapping each paper's
central idea onto a concrete part of this project: which `sec_thesis`
`CLAUDE.md` rule already encodes a loop-engineering principle, how your own
Claude Code sessions this semester compare to the expertise study's
findings, and one concrete way `SkillOpt`-style bounded, validated editing
could improve the `investment-philosopher` skill.

This is a **reading week** — no new code is required, though Day 4 includes
an optional design sketch.

## Four-Day Schedule

### Day 1 — Loop Engineering

- **0–10 minutes:** Review Week 18 and open the repository.
- **10–25 minutes:** Read Sections I–VI (the four-layer stack, the five moves, generator/evaluator separation).
- **25–50 minutes:** Map the five moves onto `sec_thesis`'s existing architecture.
- **50–60 minutes:** Record notes and commit.

### Day 2 — Agentic Coding and Persistent Returns to Expertise

- **0–10 minutes:** Reproduce yesterday's main idea without notes.
- **10–25 minutes:** Read the paper's key findings and Section 4 (returns to expertise).
- **25–50 minutes:** Self-assess your own recent Claude Code sessions against Table 1's expertise rubric.
- **50–60 minutes:** Record notes and commit.

### Day 3 — SkillOpt

- **0–10 minutes:** Define the session's small deliverable.
- **10–25 minutes:** Read Sections 1–3 (the text-space optimization analogy, bounded edits, the validation gate).
- **25–50 minutes:** Compare SkillOpt's loop to the `investment-philosopher` skill's current (unoptimized) design.
- **50–60 minutes:** Document decisions and commit.

### Day 4 — Synthesis and Reflection

- **0–10 minutes:** Review the week.
- **10–25 minutes:** Design sketch (optional, not required code): what would a SkillOpt-style validation gate for `investment-philosopher` need as its held-out test set?
- **25–45 minutes:** Write the required reflection.
- **45–55 minutes:** Discuss: which of the three papers changes how you'll use Claude Code for the rest of this course?
- **55–60 minutes:** Push the final commit.
